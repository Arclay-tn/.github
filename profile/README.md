## Automatic QA

**Find the break before your customer does.**

[Automatic QA](https://automatic-qa.arclay.tn) maps your website, runs real-browser checks and keeps the evidence next to every issue. You start with a URL, not a test suite.

- **Browser checks on every scan.** Broken links, JavaScript errors, accessibility (axe-core WCAG A/AA), SEO basics, mobile layout and security headers, grouped into issues with screenshots.
- **Visual regression.** Desktop and mobile screenshots compared with accepted baselines.
- **Uptime monitoring.** Checks every minute on higher plans, with alerts by email, Slack, Discord or webhook.
- **CI quality gates.** Trigger a scan of your deployed environment from CI and fail the pipeline only on new or reopened high and critical findings.
- **Made for agencies.** Monitor many client sites from one workspace, with shareable reports and README status badges.
- **Honest results.** Only verified sites you control are scanned. Findings close only after a complete re-check, and AI never decides whether a check passed.
